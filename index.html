Investor Intelligence Bot

FastAPI · ChromaDB · Google Gemini · Docker · Azure Container Apps

YouTube Comment Sentiment Analysis

scikit-learn · DVC · MLflow · GitHub Actions · Azure Container Apps · Chrome extension

An MLOps pipeline end to end: a 5-stage reproducible DVC pipeline, an MLflow model registry, and CI/CD that trains, tests, blocks promotion below 0.80 accuracy, then deploys to Azure pinned to the commit SHA — on every green run. Served to a Manifest V3 Chrome extension that analyses any video in place.

The classifier is deliberately small — TF-IDF and logistic regression, chosen for fast inference inside a browser plugin. Swapping in a transformer is a data and compute question; the pipeline around it does not change.

Trimmed — most of the elapsed time is YouTube lazy-loading the comment section, not the API, which replies in well under a second once comments are collected.

Try the model Source Extension

The live page lets you classify your own comments. For the raw API:

curl -X POST https://yt-sentiment-api.ashysmoke-d4f578eb.koreacentral.azurecontainerapps.io/predict   -H "Content-Type: application/json"   -d '{"comments":["this is amazing","worst video ever","it was okay"]}'

The Chrome extension is the intended front end; it loads unpacked from the extension repo above (chrome://extensions → Developer mode → Load unpacked).
